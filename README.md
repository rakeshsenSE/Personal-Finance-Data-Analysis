# Personal Finance Data Analysis 📊

This project analyzes personal financial transactions using MySQL Workbench to uncover insights into income, expense categories, and monthly balances.

## 📂 Project Structure
- `schema_and_data.sql`: Contains the database setup, table structures (`accounts`, `categories`, `transactions`), and dummy dataset.
- `queries.sql`: Contains analytical SQL queries for financial metrics.

## 💡 Key Questions Answered
1. What is the total income and total expense recorded?
2. Which expense category accounts for the highest spending?
3. What is the month-over-month account balance trend?

## 🛠️ Tech Stack
- MySQL / MySQL Workbench
- Git & GitHub
